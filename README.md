# Rick and Morty Android App

This project was created as part of an Android Studio course during my Erasmus studies in Spain.

The goal of the project was to develop a native Android mobile application based on the Rick and Morty universe. The application uses the public Rick and Morty API to display information about characters, locations, and episodes from the series.

The app allows users to browse and search through data, explore different planets and dimensions, and navigate between episodes and characters using a clear and user-friendly interface.

The main focus of the project was to practice Android development in Java, working with external APIs, managing application state, designing intuitive screens, and creating a smooth mobile user experience.

The project was developed collaboratively using Git, which allowed the team to manage changes and work together in a more professional development workflow.
